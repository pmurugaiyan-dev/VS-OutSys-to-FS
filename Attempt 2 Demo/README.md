# Trade Module - .NET 8 Web API

Migrated from OutSystems Trade module to .NET 8 Web API.

## Overview

This application was generated by the OutSystems to .NET Migration Agent System, converting the Trade module from OutSystems to a modern .NET 8 Web API.

## Source

- **OutSystems Module**: Trade.oml
- **Original Application**: DemoApplication.oap

## Components

### Entities

| Entity | Description |
|--------|-------------|
| **NewEntry** | Main trade entry with fields: Weight_Lbs, BarCode, BranchName, Items, Time, Final |
| **MasterDetailItem** | Detail items for master-detail relationship with NewEntry |

### API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/NewEntry` | Get all entries |
| GET | `/api/NewEntry/{id}` | Get entry by ID |
| GET | `/api/NewEntry/{id}/details` | Get entry with detail items |
| POST | `/api/NewEntry` | Create new entry |
| PUT | `/api/NewEntry/{id}` | Update entry |
| DELETE | `/api/NewEntry/{id}` | Delete entry |
| GET | `/api/NewEntry/branch/{branchName}` | Get entries by branch |
| GET | `/api/NewEntry/finalized` | Get finalized entries |

### UI Routes

| Route | Description |
|-------|-------------|
| `/Trade` | Razor Pages UI for NewEntry management |
| `/swagger` | Swagger API documentation |

## Database

Using InMemory database for demo purposes. The application seeds sample data on startup.

To switch to SQL Server, update `Program.cs`:

```csharp
builder.Services.AddDbContext<TradeDbContext>(options =>
    options.UseSqlServer(builder.Configuration.GetConnectionString("DefaultConnection")));
```

## Migration Notes

### From OutSystems

- **NewEntry entity** mapped from OutSystems entity with fields:
  - Weight_Lbs → WeightLbs (decimal)
  - BarCode → BarCode (string)
  - BranchName → BranchName (string)
  - Items → Items (int)
  - Time → Time (DateTime)
  - Final → Final (bool)

- **MasterDetailItem structure** converted to related entity with:
  - Foreign key relationship to NewEntry
  - Additional fields: ItemName, Quantity, UnitPrice

### Generated Components

1. **Parser Agent** - Analyzed Trade.xml for entity definitions
2. **Analyzer Agent** - Assessed complexity (simple entity structure)
3. **Configuration Agent** - Generated .csproj, Program.cs, appsettings.json
4. **Compilation Agent** - Verified build success
